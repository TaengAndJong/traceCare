# .claude/rules/git.md

> 이 파일에는 git 작업 시 매번 지켜야 하는 짧은 체크리스트만 작성한다 (근거 설명은 docs로 링크).

## 기본 규칙
- 작업 전 `git status`로 현재 상태를 확인한다
- 기존 변경사항을 임의로 되돌리지 않는다
- 사용자가 작성한 변경사항을 덮어쓰지 않는다
- 명시적인 요청이 없으면 commit을 생성하지 않는다
- force push를 수행하지 않는다
- 작업 후 변경된 파일을 확인한다
- 대규모 변경 전에는 현재 작업 상태를 확인한다
- 다른 작업자가 수행한 변경사항을 임의로 제거하지 않는다
